# The Dyonian Legal Code

The supreme codified legal system of the **Departement-Of-Dyon** polity.
This repository is the canonical text of the Code. All other law repositories
in the organization derive their authority from it.

## Structure of the Code

| Book | Document | Scope |
|------|----------|-------|
| I | [constitution.md](constitution.md) | Organic law — branches, sovereignty, rights, amendment |
| II | [civil-code.md](civil-code.md) | Persons, property, contracts, obligations, torts |
| III | [penal-code.md](penal-code.md) | Crimes, defenses, penalties, sentencing |
| IV | [procedure.md](procedure.md) | Courts, due process, evidence, enforcement |

## Foundational Articles

The Code is built on seven axiomatic articles, each maintained in its own
repository:

1. **Causality** — every effect has a cause (`law-causality`)
2. **Entropy** — order requires effort; cleanup is a civic duty (`law-entropy`)
3. **Gravity** — what goes up must come down (`law-gravity`)
4. **Time** — time is the only non-renewable resource (`law-time`)
5. **Identity** — a polity is defined by what it ships (`law-identity`)
6. **Code** — code that works is law (`law-code`)
7. **Chaos** — chaos is order over-applied (`law-chaos`)

Supplementary articles: `law-motion`, `law-focus`, `law-silence`.

## Reference Corpus

The Code is interpreted against real-world legal corpora hosted in this
organization: the U.S. Constitution and amendments, the U.S. Code, the Code of
Federal Regulations, state codes, Supreme Court opinions, treaties, and GPO
bulk data. See the `constitution`, `bill-of-rights`, `us-code`, `cfr`,
`state-laws`, `supreme-court`, `us-treaties`, and `govinfo-bulk` repositories.

## Status

This is a personal legal-art project. The Code has no jurisdictional force;
it is a coherent fictional legal system maintained for study and amusement.
